在 Unity 與 Unreal Engine 之間移轉動畫。
拖入資源包，挑選需要的片段，只匯出這些。

免費開源 · Windows x64

## 功能特色

- **拖入即檢視.** 拖入 `.unitypackage`、資料夾、`.anim` 或 `.fbx`，即可搜尋、篩選並選取片段。
- **匯出前先預覽.** 可以先在應用程式內播放任一片段。
- **原始檔或烘焙.** 直接擷取原始檔，或用相符的骨架將計算後的動畫烘焙為 FBX。
- **Humanoid 與二進位片段.** 由 Unity 為你計算。
- **Unity 與 Unreal 互通.** 提供 Unreal 匯入輔助，並可匯出 FBX 與 manifest 回到 Unity。
- **本機原生應用程式.** C++20 主程式、本機 WebView2 介面，以及 Python/Blender 轉換程序。
- **15 種語言.** 語言設定會被儲存，阿拉伯文支援由右至左排版。
- **永久免費.** 採用 MIT 授權。
