Unity와 Unreal Engine 사이에서 애니메이션을 옮겨요.
패키지를 끌어다 놓고, 필요한 클립만 골라 내보내세요.

무료 오픈소스 · Windows x64

## 주요 기능

- **끌어다 놓고 확인** `.unitypackage`, 폴더, `.anim`, `.fbx`를 놓으면 클립을 검색, 필터, 선택할 수 있어요.
- **내보내기 전에 미리보기** 앱에서 클립을 먼저 재생해 볼 수 있어요. 기본 캐릭터가 포함되어 있어 Unreal 없이도 되고, Humanoid·바이너리 클립은 Unity Editor가 필요해요. Windows 앱은 Unity Hub로 설치한 Unity Editor를 자동으로 연결해요.
- **원본 추출 또는 베이크** 원본 파일을 그대로 꺼내거나, 호환되는 스켈레톤으로 평가한 애니메이션을 FBX로 베이크해요.
- **Humanoid와 바이너리 클립** Unity를 통해 평가해 줘요.
- **Unity와 Unreal을 오가며** Unreal 가져오기 도우미와, Unity로 되돌리는 FBX·manifest 내보내기를 지원해요.
- **로컬 네이티브 앱** C++20 호스트, 로컬 WebView2 UI, Python·Blender 변환 워커로 동작해요.
- **15개 언어** 언어 설정이 저장되고, 아랍어는 오른쪽→왼쪽 배치를 지원해요.
- **평생 무료** MIT 라이선스예요.
