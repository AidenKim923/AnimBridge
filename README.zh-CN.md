在 Unity 和 Unreal Engine 之间迁移动画。
拖入资源包，挑选需要的片段，只导出这些。

免费开源 · Windows x64

## 功能特点

- **拖入即查看.** 拖入 `.unitypackage`、文件夹、`.anim` 或 `.fbx`，即可搜索、筛选并选择片段。
- **导出前先预览.** 可以先在应用内播放任意片段。
- **原始文件或烘焙.** 直接提取原始文件，或用匹配的骨架将计算后的动画烘焙为 FBX。
- **Humanoid 与二进制片段.** 由 Unity 为你计算。
- **Unity 与 Unreal 互通.** 提供 Unreal 导入辅助，并可导出 FBX 和 manifest 回到 Unity。
- **本地原生应用.** C++20 主程序，本地 WebView2 界面，以及 Python/Blender 转换进程。
- **15 种语言.** 语言设置会被保存，阿拉伯语支持从右到左排版。
- **永久免费.** 采用 MIT 许可证。
