UnityとUnreal Engineの間でアニメーションを移せます。
パッケージをドロップして、必要なクリップだけ選んで書き出せます。

無料・オープンソース · Windows x64

## 主な機能

- **ドロップして確認.** `.unitypackage`、フォルダー、`.anim`、`.fbx`をドロップすると、クリップを検索・絞り込み・選択できます。
- **書き出す前にプレビュー.** アプリ内でクリップを先に再生できます。
- **オリジナルまたはベイク.** 元ファイルをそのまま取り出すか、対応するスケルトンで評価したアニメーションをFBXにベイクします。
- **Humanoidとバイナリクリップ.** Unityで評価します。
- **UnityとUnrealを行き来.** Unrealインポート補助と、Unityへ戻すFBX・マニフェストの書き出しに対応します。
- **ローカルで動くネイティブアプリ.** C++20ホスト、ローカルWebView2 UI、Python/Blender変換ワーカーで動作します。
- **15言語.** 言語設定は保存され、アラビア語は右から左のレイアウトに対応します。
- **ずっと無料.** MITライセンスです。
