انقل الرسوم المتحركة بين Unity وUnreal Engine.
أسقط الحزمة، واختر المقاطع التي تريدها، وصدّرها وحدها.

مجاني ومفتوح المصدر · Windows x64

## الميزات

- **أسقط وافحص.** أسقط ملف `.unitypackage` أو مجلدًا أو `.anim` أو `.fbx`، ثم ابحث في المقاطع وصفّها واخترها.
- **معاينة قبل التصدير.** شغّل أي مقطع داخل التطبيق أولًا.
- **الأصل أو الخبز.** استخرج الملفات الأصلية، أو اخبز الرسوم المقيَّمة إلى FBX مع هيكل عظمي مطابق.
- **مقاطع Humanoid والمقاطع الثنائية.** يقيّمها Unity نيابةً عنك.
- **من Unity إلى Unreal والعكس.** مساعدات استيراد إلى Unreal، وتصدير FBX وملف manifest عائدًا إلى Unity.
- **محلي وأصلي.** مضيف بلغة C++20 مع واجهة WebView2 محلية وعمليات تحويل بلغة Python/Blender.
- **15 لغة.** يُحفظ اختيار اللغة، مع تخطيط من اليمين إلى اليسار للعربية.
- **مجاني دائمًا.** بترخيص MIT.
