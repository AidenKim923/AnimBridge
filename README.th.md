ย้ายแอนิเมชันระหว่าง Unity และ Unreal Engine
วางแพ็กเกจ เลือกเฉพาะคลิปที่ต้องการ แล้วส่งออกได้เลย

ฟรีและโอเพนซอร์ส · Windows x64

## จุดเด่น

- **วางแล้วดูได้ทันที.** วาง `.unitypackage` โฟลเดอร์ `.anim` หรือ `.fbx` แล้วค้นหา กรอง และเลือกคลิปได้
- **ดูตัวอย่างก่อนส่งออก.** เล่นคลิปใดก็ได้ในแอปก่อน
- **ไฟล์ต้นฉบับหรือเบก.** ดึงไฟล์ต้นฉบับออกมา หรือเบกแอนิเมชันที่ประเมินแล้วเป็น FBX โดยใช้โครงกระดูกที่ตรงกัน
- **คลิป Humanoid และไบนารี.** Unity ประเมินให้
- **Unity ไป Unreal และกลับ.** มีตัวช่วยนำเข้า Unreal และส่งออก FBX กับ manifest กลับไปที่ Unity
- **ทำงานในเครื่อง เป็นเนทีฟ.** โฮสต์ C++20 พร้อม UI WebView2 ในเครื่อง และตัวประมวลผลแปลงไฟล์ด้วย Python/Blender
- **15 ภาษา.** จดจำภาษาที่เลือกไว้ และรองรับการจัดวางขวาไปซ้ายสำหรับภาษาอาหรับ
- **ฟรีตลอดไป.** สัญญาอนุญาต MIT
